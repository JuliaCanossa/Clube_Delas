# Clube Delas

**Um espaço para se organizar, evoluir e se cuidar.**

O Clube Delas é uma plataforma web voltada ao desenvolvimento pessoal feminino, criada para incentivar meninas a desenvolverem hábitos, ampliarem seus conhecimentos e explorarem novos interesses.

A proposta é mostrar que a evolução pessoal acontece por meio de pequenas ações diárias, respeitando o tempo e a realidade de cada pessoa, sem cobranças excessivas ou comparações.

## Objetivo do Projeto

Criar um espaço digital que incentive o desenvolvimento pessoal feminino por meio de conteúdos inspiradores, ferramentas de organização e acompanhamento de hábitos.

O projeto busca estimular a autonomia, o autoconhecimento e a construção de uma rotina mais equilibrada.

## Funcionalidades

- **Página inicial:** apresentação do Clube Delas e de sua proposta.
- **Cadastro e Login:** criação de conta e acesso à plataforma.
- **Conteúdos:** dicas, listas, inspirações e materiais sobre desenvolvimento pessoal.
- **Checklist de hábitos:** acompanhamento dos hábitos adicionados pela usuária.
- **Dashboard:** visualização do progresso por meio de indicadores e gráficos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- API - WEB - DATA - VIZ
- MySQL
- Chart.js

## Estrutura do Projeto

O projeto é dividido em duas partes principais:

**Front-end:** responsável pela interface e interação com a usuária, desenvolvido com HTML, CSS e JavaScript.

**Back-end:** responsável pelo processamento das informações, comunicação com o banco de dados e disponibilização dos dados por meio de uma API desenvolvida com Node.js.

**Banco de Dados:** MySQL, utilizado para armazenar as informações das usuárias e seus hábitos.

## Indicadores da Dashboard

A dashboard apresenta informações relacionadas ao acompanhamento dos hábitos, permitindo visualizar:

- Hábitos concluídos;
- Constância semanal;
- Sequência de dias;
- Evolução dos hábitos por meio de gráficos.

## Organização e Desenvolvimento

O desenvolvimento do projeto foi organizado com o auxílio do Trello para gerenciamento das tarefas e GitHub para versionamento e armazenamento do código-fonte.

## Objetivo de Desenvolvimento Sustentável (ODS)

O Clube Delas está relacionado ao **ODS 3 — Saúde e Bem-Estar**, da Organização das Nações Unidas (ONU), por incentivar práticas de autocuidado, organização da rotina e construção de hábitos que contribuam para o bem-estar físico e mental.
